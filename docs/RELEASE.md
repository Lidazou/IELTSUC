# IELTSUC 1.3.1 · 公开发行版

Windows x64 本地雅思陪考应用。

- 每日目标圆环、考试倒计时、学习日历。
- 中文提示打字回忆、听写、即时反馈、上一词 / 下一词和错词重练。
- 本地 OCR、个人词书、自己的音频和试卷导入。
- Ollama 句子 / 作文点评与试卷解析。
- 黑白主题与响应布局，黑底白色 U＋图标。

## 下载与启动

下载 IELTSUC-1.3.1-win-x64.exe，核对 SHA256SUMS.txt 后在 Windows 启动。EXE 不需要 Node.js；Ollama 和模型需另行安装。

公开版只附 10 条示例词，不含个人数据库、第三方教材、音频、完整真题库或模型权重。使用自己的合法资料导入，见 VOCABULARY.md。部署见 DEPLOYMENT.md，本地模型见 OLLAMA.md。
